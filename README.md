# AI-PsAssistant

## AI智能体控制Photoshop

---

### 功能

- 118个PS操作工具
- 支持通义千问、智谱、DeepSeek、Claude、GPT
- 参考图上传
- **AI视觉分析（让AI"看懂"图片）**
- **自定义视觉模型接口（支持任意OpenAI/Claude兼容模型）**
- **闭环修图（AI自动"看→改→看→改"循环）**
- API Key安全保密（只存本机）

---

### 两个模型，各司其职

| 模型 | 作用 | 说明 |
|------|------|------|
| 聊天模型 | 控制PS修图 | Setup.bat里选 |
| 视觉模型 | 看懂图片、评估效果 | 界面"模型设置"里加 |

视觉模型独立配置，不影响聊天模型。

---

### 三大功能

| 功能 | 按钮 | 作用 |
|------|------|------|
| 参考图 | 参考图 | 上传图片、加入对话 |
| 视觉分析 | 参考图面板内 | 让AI看图片、给建议 |
| 闭环修图 | 闭环修图 | AI自动循环修图直到达标 |

---

### 闭环修图怎么用

1. 在Photoshop里打开要修的图
2. 配置好视觉模型（模型设置）
3. 点"闭环修图"，填写目标（如"做成白底电商图"）
4. AI自动：看当前图 → 评估哪里没达标 → 执行修改 → 再看 → 再改
5. 最多循环3轮

### 安装步骤

#### 第1步：安装Node.js

访问 https://nodejs.org/ 下载安装LTS版本

#### 第2步：首次配置

双击 `Setup.bat`，按提示配置API Key

> 本包已内置所有依赖（node_modules），无需联网安装

#### 第3步：添加视觉模型（可选）

1. 打开程序后，点右上角"模型设置"按钮
2. 选一个预设，或填自定义模型
3. 填写API Key
4. 点"保存"

#### 第4步：启动

1. 打开Photoshop
2. 双击 `Start.bat`
3. 浏览器访问 http://localhost:5175

### 使用方法

#### AI控制PS

在聊天框输入指令：
- "把图片调亮一点"
- "增加对比度"
- "把背景去掉"

#### 让AI看图分析

1. 点右上角"参考图"按钮
2. 上传图片
3. 输入目标（例如"这张图怎么改进"）
4. 点"让AI看图分析"

#### 使用参考图

1. 上传图片
2. 点击"在对话中使用"
3. 补充说明，发送

### 常见问题

**Q: 双击bat文件闪退？**
A: 右键选择"以管理员身份运行"

**Q: 视觉分析失败？**
A: 先点"模型设置"添加一个视觉模型的API Key

**Q: 浏览器打不开？**
A: 确认服务已启动（黑色窗口保持打开）

**Q: AI不操作PS？**
A: 确认Photoshop已打开，且有图片在编辑

**Q: 提示API错误？**
A: 重新运行 `Setup.bat`
