# PS智能体 使用教程（小白版）

欢迎使用！这个软件能让 AI 自动帮你修图。你只需要用大白话告诉它要干什么，它就会自动操作 Photoshop 完成。

---

## 一、开始前，你需要准备 2 样东西

1. **Photoshop**（电脑上已经装好，版本 2024 或更新）
2. **一个 API Key**（就是一把"钥匙"，让 AI 能联网工作）

> API Key 怎么弄？看下面的"第二步"，大概 5 分钟搞定。

---

## 二、获取 API Key（最关键的一步，5 分钟）

推荐用**阿里云百炼**（国内、便宜、稳定）。跟着做：

### 第 1 步：注册账号
1. 打开浏览器，访问：https://bailian.console.aliyun.com/
2. 用支付宝/淘宝账号登录（没有就注册一个）

### 第 2 步：开通服务
1. 登录后，第一次会提示"开通模型服务"
2. 点"同意并开通"（免费开通，不收费）

### 第 3 步：创建 API Key（钥匙）
1. 点右上角你的头像 → **API-KEY 管理**
2. 点 **创建新的 API-KEY**
3. 复制生成的那串东西（`sk-` 开头的一长串字符）
4. **把它保存到记事本里**，后面要用

> ⚠️ 注意：这个 Key 是你的"钥匙"，别发给别人。

### 充值一点点钱（可选，但建议）
- 百炼是按用量扣费的，新用户通常有免费额度
- 用完之后，在"费用中心"充值 10 块钱就能用很久

---

## 三、安装软件（2 分钟）

1. 找到卖家发给你的压缩包（`PS智能体.zip`）
2. **右键** → 选择 **"全部解压缩"**
3. 会得到一个文件夹，打开它

---

## 四、首次配置（跟着做就行）

1. 双击文件夹里的 **`Setup.bat`**（名字是 Setup）

2. 如果是第一次，它会**自动帮你下载安装 Node.js**（约 32MB，等它自己装完，中间如果弹出权限提示，点"是"）

3. 装完后，会出现一个选择菜单，问你要用哪个模型：

   ```
   请输入数字 (1-7):
   ```

   **推荐输入 `1`**（通义千问，便宜又能看图片）

4. 然后它会让你填 API Key：
   ```
   请输入你的通义千问 API Key:
   ```
   把**第二步**里保存的那串 `sk-xxx...` 粘贴进去，按回车

5. 等它提示"配置完成"就成功了

---

## 五、配置视觉模型（让 AI 能"看图"，2 分钟）

1. 双击文件夹里的 **`Start.bat`**（名字是 Start）
2. 会弹出一个黑色窗口（**不要关它**），过几秒会自动打开网页
3. 如果没自动打开，手动打开浏览器访问：**http://localhost:5175**

4. 打开网页后，点右上角的 **"模型设置"** 按钮

5. 在右侧面板里：
   - 点一下预设里的 **"通义千问 Qwen-VL-Max"**
   - 在 **API Key** 那一栏，粘贴你**第二步**保存的同一个 Key
   - 点 **"保存并切换"**

> 完成后，AI 就能"看懂"你的图片了。这一步只做一次。

---

## 六、开始使用（核心功能）

### 功能 1：用大白话改图

1. 先在 Photoshop 里打开你要修的图
2. 在网页左边的聊天框，直接打字：
   - "把图片调亮一点"
   - "把背景去掉"
   - "增加对比度"
3. 按回车，AI 就会自动操作 Photoshop 完成

### 功能 2：让 AI 看图给建议

1. 点右上角 **"参考图"** 按钮
2. 上传一张图片
3. 输入你的问题，比如"这张图怎么改进"
4. 点 **"让AI看图分析"**，AI 会告诉你哪里要改

### 功能 3：闭环修图（自动反复修到满意）

这是最厉害的功能，AI 会自己"看→改→看→改"循环：

1. 点右上角 **"闭环修图"** 按钮
2. 在框里填你的目标，例如：
   - "把这张产品图做成白色背景的专业电商图"
   - "把人物皮肤修得自然光滑"
3. 点 **"开始闭环修图"**
4. AI 会自动操作，改完自己检查，不满意继续改，直到达标

## 七、常见问题

**Q1：双击 bat 后黑窗口一闪就关了？**
A：先确认是**解压后**双击的（不要在压缩包里直接点）。还不行就右键 → "以管理员身份运行"。

**Q2：提示"未检测到 Node.js"？**
A：正常，Setup.bat 会自动帮你下载安装，等它装完即可。

**Q3：提示"Photoshop 未连接"？**
A：先打开 Photoshop 并载入一张图片，再操作。

**Q4：提示"API错误(401)"？**
A：API Key 填错了。去"模型设置"里重新粘贴正确的 Key。

**Q5：AI 说看不懂图？**
A：说明视觉模型没配好，回到"第五步"重新配置。

**Q6：改的效果不好？**
A：把需求说得更具体一点。比如别只说"好看点"，要说"背景调成纯白、产品居中、光线均匀"。

3. 闭环修图一次最多 2 轮，不会无限烧钱
